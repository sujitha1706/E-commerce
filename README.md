A fully functional e-commerce website with product listings, shopping cart, wishlist, user login/registration, and an admin panel — built with HTML, CSS, JavaScript, and PHP.

---

## ✨ Features

- ✅ Home page with featured products and categories
- ✅ Product pages: Electronics, Mobiles, Laptops, Headphones, Watches, Men's & Women's fashion
- ✅ Shopping cart with add/remove functionality
- ✅ Wishlist management
- ✅ User login, registration, and logout
- ✅ Admin panel for product management
- ✅ Responsive design for all screen sizes

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | HTML5, CSS3, JavaScript |
| Backend | PHP |
| Database | MySQL (via config.php) |

## ⚙️ Setup Instructions

```bash
# 1. Clone the repository
git clone https://github.com/sujitha1706/E-commerce.git

# 2. Move project to your web server root
# For XAMPP: C:/xampp/htdocs/E-commerce
# For WAMP:  C:/wamp/www/E-commerce

# 3. Create MySQL database and update config.php
# DB_HOST = localhost
# DB_USER = your_username
# DB_PASS = your_password
# DB_NAME = ecommerce

# 4. Start Apache and MySQL in XAMPP/WAMP

# 5. Open browser and go to:
http://localhost/E-commerce/home.html
```
